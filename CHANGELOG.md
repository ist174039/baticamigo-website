# Changelog

Este projeto segue Semantic Versioning para versões publicadas da aplicação. Alterações ainda não promovidas para produção permanecem em `Unreleased`.

## Unreleased

- Rastreabilidade dos 27 requisitos e 42 normas/controlos.
- Hardening de privacidade de calendário/presenças.
- Firebase Rules/Storage Rules versionadas com acesso direto deny-all.
- Gates de readiness, risco, PIA/DPIA, acessibilidade e continuidade.
- Contrato OpenAPI 3.1 e respostas de erro RFC 9457.
- Modelo físico de dados versionado, mapa jurídico Portugal/UE e protocolos de acessibilidade/usabilidade.
- Observabilidade/tabletop fail-closed, readiness ligado ao release SHA e revisão de release/rollback.
- Hardening de uploads privados contra PDF ativo e Office com VBA/ActiveX/embeddings.
