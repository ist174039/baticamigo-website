# ISO/IEC 27001:2022 — Statement of Applicability (draft)

Este documento **não é uma SoA aprovada** nem prova de certificação.

## Escopo técnico proposto
Website público, área privada, administração, APIs, Firebase Auth/Firestore/Storage, CI/CD e operação associada.

## Referências
O catálogo detalhado é mantido em `docs/security/iso-27002-control-map.md`.

## Regras da SoA
Para cada controlo:
- aplicabilidade;
- justificação;
- implementação;
- evidência;
- owner;
- exceção;
- revisão.

## Estado
A seleção formal de controlos, metodologia de risco, aceitação residual, políticas organizacionais e auditoria interna continuam por aprovar. Até então, BA-STD-026 permanece Lacuna.
