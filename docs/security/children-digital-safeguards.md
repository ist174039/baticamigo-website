# Salvaguardas digitais para crianças e famílias

## Princípios técnicos já aplicados
- perfis de aluno e encarregado separados;
- relação encarregado–educando usada na autorização;
- presenças, avaliações e records de outros alunos não são expostos;
- calendário partilhado remove identidades de participantes não autorizados;
- dados privados passam pela API server-side;
- testes e CI usam apenas dados sintéticos;
- plataforma privada não é usada para publicidade comportamental;
- reporting evita grupos pequenos quando aplicável;
- sínteses pedagógicas são determinísticas/revisáveis e não são diagnóstico clínico ou decisão automatizada.

## Controlos obrigatórios antes de GO
- linguagem e avisos adequados aos utilizadores;
- finalidade/base legal e representação aprovadas;
- retenção definida;
- canais de reporte/escalamento;
- revisão dos fluxos com representantes adequados sem recolher dados desnecessários;
- acessibilidade e capacidade de pedir ajuda/correção.

## Gate
Nenhum fluxo dirigido a menores é considerado validado apenas com testes técnicos. A revisão humana/organizacional permanece obrigatória.
